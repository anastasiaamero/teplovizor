# Тепловизор

Два браузерных инструмента для градиентных эффектов. Работают целиком в браузере, без сервера и без установки: картинки никуда не загружаются.

## Тепловизор — `index.html`
Накладывает на картинку (PNG, SVG, JPG) градиентную «тепловую карту» и анимирует перелив.

- 13 готовых градиентов и стилей, редактор градиента, сохранение своих
- режим «Объект»: фон картинки отделяется автоматически или пипеткой
- свечение, подсветка края, объём, блики, штрихи, фон из четырёх цветов
- точки, полосы, бумага, зерно, шум, текстовые слои (Helvetica)
- бесшовная анимация перелива
- экспорт PNG, видео (MP4/WebM) и GIF со сжатием

## Наложение — `overlay.html`
Статичная обработка картинки.

- градиент поверх картинки: по яркости, линейно или по кругу
- режимы наложения: обычный, умножение, экран, перекрытие, мягкий свет, цветность, светлее, темнее
- прогрессивное размытие по точкам: движение, зум или обычное
- форматы кадра 1:1, 4:5, 3:4, 2:3, 16:9, 9:16, 3:2
- экспорт PNG или JPG

## Запуск
Откройте `index.html` в браузере с WebGL 2 (свежие Chrome, Safari, Firefox) или включите GitHub Pages для этого репозитория.
